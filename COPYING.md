# Copying Lepse

All packages in this monorepo are licensed under their respective licenses. Refer to each package's LICENSE file for more information. If a LICENSE file is not available, the package falls back to All Rights Reserved.

A package may also have its own COPYING.md file, it does not replace the main COPYING.md at the root of the monorepo, but adds to it, and may override its rules for the respective package.

## Branding

The use of Lepse branding, including but not limited to logos, images, and any variations thereof, is strictly prohibited without explicit permission from a Lepse representative. This includes trademarks, package codenames, other branding assets, or anything that would impersonate Lepse.

If you fork this repository for your own purposes, you must remove all such branding assets from your fork.
